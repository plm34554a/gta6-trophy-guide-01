Leonida Legend is an offline GTA VI trophy guide and tracker: all 55 PS5 trophies with their official names, descriptions and grades, a sourced guide for each one, a five-step platinum roadmap, a clear warning for the one missable trophy, filters by kind and grade, a spoiler shield for story trophies, and a checklist whose progress persists locally and can be exported and imported as a file. Fully static, no build step, no network at runtime.

## Run it

```sh
node serve.ts
```

Then open the local address it prints in a desktop browser. To produce the hand-in output instead: `MAKEFUN_OUTPUT_DIR=out node main.ts`.
