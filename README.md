Leonida Legend is a fully offline guide and tracker for the Grand Theft Auto VI PlayStation 5 trophy list. It covers all 55 trophies — one platinum, two gold, six silver and forty-six bronze — each shown with its official name, description and grade, and each paired with a plain-language guide whose sources are cited right alongside it. The trophies are organised into a five-step platinum roadmap that orders them the way you would actually earn them, and the list's single missable trophy, Positive Mental Attitude, gets a prominent warning banner so a Chapter 1 opportunity is not lost for good. You can filter and search the checklist by kind, grade and completion status, and a spoiler shield keeps story trophy names and descriptions hidden until you choose to reveal them. Ticking trophies off saves your progress in the browser's localStorage, and the whole checklist can be exported to a file and imported back on another machine. Everything is static files with no build step and no network calls at runtime, so it works anywhere a browser does.

## Run it

```sh
node serve.ts
```

Then open the local address it prints in a desktop browser. To produce the hand-in output instead: `MAKEFUN_OUTPUT_DIR=out node main.ts`.
